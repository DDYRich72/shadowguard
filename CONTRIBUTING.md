# Contributing

ShadowGuard is published as a completed, read-only open-source resource. The
upstream repository is intended to be archived after the `v1.0.0` snapshot.

The project does not promise to accept pull requests, review issues, provide
implementation help, maintain a roadmap, publish updates, or operate a support
or security-response service. Please do not submit secrets, production data,
customer information, or vulnerability details to a public issue.

You may fork and modify the project under the Apache License 2.0. Fork
maintainers are responsible for their own contribution rules, releases,
security process, infrastructure, user support, and compliance obligations.

Third-party forks and deployments must not imply RLS Solutions endorsement or
claim to be an official hosted ShadowGuard service. See `NOTICE`.
