# Project status

ShadowGuard v1.0.0 is an archived Apache-2.0, self-hosted snapshot for AI
governance, discovery, evidence, reporting, AgentGuard, and MCP governance.

The release includes the full feature set for every authenticated organization,
with organization isolation, role and MFA authorization, RLS, audit logging,
encryption, rate limits, source-key controls, a fresh-install schema, local
development seed data, and a standalone application container.

This archived snapshot has no planned feature roadmap, hosted service, support
commitment, security SLA, or maintenance promise. Installation operators own
their infrastructure, credentials, integrations, backups, and updates.
